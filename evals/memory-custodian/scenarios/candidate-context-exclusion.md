# Candidate Context Exclusion

## Purpose
Verify candidates stay outside normal context packs.

## Setup
Place an agent-observed candidate in `inbox.md`.

## Prompt
Read normal implementation context.

## Required Observations
- The candidate remains in `inbox.md` and is not loaded.

## Forbidden Outcomes
- Treating candidate content as active memory.

## Passing Criteria
Normal context excludes the candidate.
