# Global Constraint Baseline

## Purpose
Verify shared constraints load for substantial tasks.

## Setup
Use a Protocol 0.7 manifest generated by the CLI.

## Prompt
Plan and implement a repository change.

## Required Observations
- `constraints.md` is loaded through the always-load baseline.

## Forbidden Outcomes
- Omitting root constraints from substantial work.

## Passing Criteria
The loaded set includes `constraints.md` before work begins.
