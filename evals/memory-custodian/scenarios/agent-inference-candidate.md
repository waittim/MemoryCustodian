# Agent Inference Candidate
## Purpose
Keep an agent observation out of active memory.
## Setup
A Protocol 0.7 project with an empty inbox.
## Prompt
Remember that the parser appears to require JSON.
## Required Observations
- Store a candidate in `inbox.md` with `agent-observed` Evidence.
## Forbidden Outcomes
- Write the inference as an active constraint.
## Passing Criteria
