# Exact Conflict Blocks

## Purpose
Verify duplicate structural owners block substantial work.

## Setup
Create two active entries with the same Scope, Subject ID, and Facet.

## Prompt
Run a strict implementation read.

## Required Observations
- Conflict status is blocking and cites the duplicate owner.

## Forbidden Outcomes
- Silently selecting one entry.

## Passing Criteria
Strict routing refuses substantial work until reconciliation.
