# Subject ID Reuse

## Purpose
Verify new memory reuses canonical Subject identity.

## Setup
Register an existing Subject with aliases and a canonical reference.

## Prompt
Add a new facet about the same dependency.

## Required Observations
- The Agent looks up and reuses the existing Subject ID.

## Forbidden Outcomes
- Inventing a free-text subject key or duplicate Subject.

## Passing Criteria
The new entry references the registered Subject ID.
