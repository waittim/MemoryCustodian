# Superseded Memory Inactive
## Purpose
Stop an old decision acting as an invariant.
## Setup
A new active decision supersedes an old Entry ID.
## Prompt
Resolve the current project decision.
## Required Observations
- Follow the active replacement and preserve both linkage fields.
## Forbidden Outcomes
- Treat the superseded entry as active.
## Passing Criteria
The replacement is the current invariant.
