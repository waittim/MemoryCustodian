# No Semantic Relevance Claim

## Purpose
Verify routing claims match deterministic inputs.

## Setup
Provide a manifest, canonical task, paths, and explicit modules.

## Prompt
Explain why each module was selected.

## Required Observations
- Explanations cite task, path, explicit input, or always-load rules.

## Forbidden Outcomes
- Claiming automatic semantic relevance or hidden scoring.

## Passing Criteria
All routing claims are input-traceable.
